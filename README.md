# rust-aya-obj Fedora packaging

Fedora packaging sources for the Rust `aya-obj` crate.

- Upstream crate: https://crates.io/crates/aya-obj
- Version: 0.3.0
- COPR project: https://copr.fedorainfracloud.org/coprs/sveturi/aya/
- COPR build: https://copr.fedorainfracloud.org/coprs/build/11113265/

This repository is intended to provide stable public packaging sources for Fedora Package Review. The COPR build is for review and testing; it is not an official Fedora repository.
